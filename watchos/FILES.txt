TROUBLESHOOTING QUICK LINKS
================================================================================

Build Errors:
  1. Check Xcode version (15.0+)
  2. Verify watchOS deployment target (10.0+)
  3. Confirm all capabilities enabled
  4. See INTEGRATION_GUIDE.md Step 1-3

Runtime Errors:
  1. Check HealthKit permission (Info.plist)
  2. Verify App Group identifier matches
  3. Check WatchConnectivity is activated
  4. See QUICK_START.md "Common Issues"

Data Not Showing:
  1. Check HealthKit has sample data
  2. Verify permission request succeeded
  3. Check UserDefaults cache
  4. See README.md "Troubleshooting"

Complications Not Updating:
  1. Verify app group is correct
  2. Check timeline provider is called
  3. Verify refresh interval hasn't passed
  4. See INTEGRATION_GUIDE.md "Troubleshooting"
